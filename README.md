# KimBoxPC 桌面版

基于 **FongMi / TVBox** 核心协议理念打造的 Windows PC 桌面影音播放客户端。

已全面剔除在 PC 端冗余的特性（如投屏、复杂弹幕、手机端手势），专注于极致纯粹的大屏观影体验：**多配置源秒级热切换 ➔ 毫秒级极速检索 ➔ 智能线路聚合 ➔ libmpv 原生渲染无缝播放 ➔ 广告剪辑/跳过与片头片尾标记 ➔ 摸鱼老板键一键隐藏**。

> **当前版本**：`v3.14.34`（版本由 `package.json` 驱动，完整更新履历详见 [更新.md](更新.md)）。

## 一、核心特性

- ⚡ **0ms 本地快照秒开与热同步（Hot-Reload）**：
  冷启动时优先从本地持久化快照（`data/cache/config_<id>.json`）瞬间恢复，杜绝启动白屏与竞态超时；同时后台静默拉取远程更新，检测到新增站点或域名修复时自动热替换，无需重启程序。
- 🎬 **原生双核播放引擎**：
  - **mpv 原生内核（默认）**：集成 `libmpv` 原生渲染模块与 Vulkan/Direct3D 加速，内存帧直通 `<canvas>`，音频直连声卡绕开浏览器 MSE 解码瓶颈，拖拽秒响应、音画不发闷变调。
  - **ffmpeg (兼容内核)**：内置服务端流式轻量转封装引擎，只在探测到时间戳重置（DISCONTINUITY）的脏流时自动启用，专门修复老旧片源的爆音/变调；干净流仍走 hls.js，拖动是秒级。
  - **网页 (MSE) 内核（可选）**：强制 hls.js + 浏览器原生解码（缓冲跟随面板设置，默认 120 秒；Worker 解析），画面更顺、CPU 占用更低；代价是遇到跨域/证书异常的源可能起不来，且无法像 mpv 那样矫正脏源音频。
  - **一键外调 PC 本地播放器**：支持检测并拉起系统已安装的 **PotPlayer / VLC / mpv / MPC-HC / ffplay**，并无缝同步起播进度。
- 🚫 **广告处理双模式（剪掉 / 跳过）**：
  - **剪辑（默认）**：开播前把 `#EXT-X-DISCONTINUITY` 分出来的广告块**从播放列表里整块删除**再交给播放器，广告根本不存在——没有跳转卡顿，兼容模式下也不用重启转封装。
  - **跳过**：保留源原始列表，播到广告区间时自动跳到区间末尾，最稳，适合源结构异常的场合。
  - 两种方式互不影响，顶栏下拉随时切换；只删「5~120 秒的孤立短块」，异常块一律不删，宁可不拦也不误删正片。
- 🎯 **播放列表代理（分析 = 播放）**：
  部分 CDN 每次请求插的广告位置都不一样。程序会让本地服务**只拉一次** m3u8，改写分片地址后缓存，同一份文本既用于广告分析、又喂给播放器，从根本上避免「分析到的区间和实际播放对不上」。
- 🐞 **广告调试面板**：
  播放中按 **`D`**（或顶栏「🐞 调试」）即可看到本集**每段广告的起止、跳转目标、全部分块的时长/分片数**（★ 标记判定结果），底部实时显示当前位置与命中状态，支持一键复制，排错不用抓包。
- 🔍 **跨站多源并发聚合搜索**：
  一键切换「本站搜索 / 全站搜索」，全站模式下并发向当前配置源的所有可用站点发起探测（20~30 个站点平均 3~6 秒内聚合成片），智能清洗片名不可见零宽字符，同名影视精准去重合并，并实时展示响应延迟与可用线路数。
- ⏭️ **播放断点进度无缝继承**：
  换源、切线路、切集数或切换播放引擎时，统一提取并保留精确到毫秒的绝对播放秒数，新流就绪后自动平滑续播，不再重播开头。
- ✂️ **片头片尾标记（按片名记忆）**：
  一键记住「片头多少秒 / 片尾多少秒」，整部剧集跨站点、跨线路通用，播到自动跳过；片尾按「距结尾秒数」记录，与广告剪辑互不干扰。
- 🧩 **TVBox「虫包」站源（type:3 dex）**：
  内置 JVM 解析层（jlink JRE 21 + dex2jar + unidbg），支持普通 dex 虫包与 ftyguard/wexguard 加固壳：搜索、详情、起播，与普通站点一样用。首次加载一个加固站点约 10~20 秒（解壳 + 转换），之后走缓存；服务空闲 10 分钟自动退出，不常驻吃内存。
- 🐟 **全局摸鱼老板键（Boss Key）**：
  默认全局快捷键 `Alt+Q`，按下瞬间隐藏软件窗口与任务栏图标，同时彻底静音暂停音视频；再次按下即刻唤醒窗口，保持暂停状态等待手动恢复，安心无痕。

## 二、运行环境与安装指南

### 1. 运行要求

KimBoxPC 采用完全**绿色便携式**架构打包，**目标电脑不需要单独安装 Node.js**（Electron 已内置 Node.js 运行时环境）。

| 组件 | 是否必需 | 说明 |
| :--- | :---: | :--- |
| **Windows 操作系统** | ✅ 必需 | Windows 10 / Windows 11 (64 位) |
| **Electron 运行时** | ✅ 必需 | 安装版已内置；便携版位于 `node_modules\electron\` |
| **libmpv 原生动态库** | ✅ 必需 | `native\lib\libmpv-2.dll` + `native\build\Release\mpv_native.node` |
| **JVM 解析层（虫包站源）** | ⚪ 可选 | 随包 `runtime\jre`（JRE 21）与 `jvm\`（companion-service.jar + 依赖）；只有配置里带 `type:3` 虫包站点时才会启动 |
| **VC++ 2015-2022 运行库** | ✅ 必需 | 缺失时运行随包的 `tools\VC_redist.x64.exe` 或 `修复运行环境.bat` |
| **随附 ffmpeg 组件** | ⚪ 备用 | `ffmpeg\ffmpeg.exe`，供「ffmpeg (兼容)」内核转封装使用 |
| **Node.js (系统环境)** | ❌ 不需要 | 桌面版开箱即用，无需配置系统环境变量 |

### 2. 安装版（推荐）

下载 **`KimBoxPC_v<版本>_Setup.exe`** 后双击安装：

1. 若弹出「Windows 已保护你的电脑」，点 **「更多信息」➔「仍要运行」**（程序未购买数字签名，属正常现象）；
2. 一路「下一步」即可，**按当前用户安装**到 `%LOCALAPPDATA%\Programs\KimBoxPC`，不需要管理员权限、不弹 UAC；
3. 安装完成后自动创建 **桌面快捷方式** 与 **开始菜单项**，并可直接勾选「启动 KimBoxPC」；
4. 卸载：Windows 设置 ➔「应用」里找到 **KimBoxPC** 卸载，或运行安装目录下的 `unins000.exe`。
   > 卸载会清理缓存与临时文件，但**保留 `data\` 目录**（配置源、收藏、观看历史），不会误删你的数据；如需彻底清空，手动删除该目录即可。

### 3. 便携版（解压即用）

1. **解压前解除文件锁定（重要）**：
   右键 `.zip` ➔「属性」➔ 勾选「解除锁定」➔「确定」，再解压。
   > *说明：Windows 会给网络下载的文件加安全标记，不解除可能导致 `libmpv-2.dll` 被拦截。*
2. 解压到任意路径（例如 `D:\Software\KimBoxPC`），保持子目录结构完整；
3. 双击 **`创建快捷方式.bat`** 生成桌面快捷方式；
4. 双击 **`KimBoxPC 桌面版`** 快捷方式启动。

### 4. 环境体检与一键修复

首次启动报错、提示缺运行库或播放无声时，双击根目录的 **`修复运行环境.bat`**，脚本会自动：

- 检测并静默安装 VC++ 运行库（`tools\VC_redist.x64.exe`）；
- 批量解除目录内文件的安全锁定；
- 校验 Vulkan / libmpv 核心文件完好性。

### 5. 端口被占用

默认端口 `3980`，若被其他程序占用：用记事本打开根目录 **`port.txt`**，改成空闲端口（如 `3988`），重启软件即可。

## 三、配置文件范例与参数详解

KimBoxPC 完整兼容标准的 **TVBox / FongMi (蜂蜜)** 订阅配置协议，支持传入标准的远程 `http(s)://` JSON 订阅链接，或本地 JSON 文件路径。

> ⚠️ **规范声明**：下文所有配置均为语法结构教学范例，包含的域名均为纯示例假地址（如 `example.com`），**不指向任何真实服务器**。在实际使用中，请换入合法有效的配置内容。

### 1. 标准 JSON 配置文件范例

```json
{
  "spider": "https://example.com/spiders/custom_spider.jar",
  "wallpaper": "https://example.com/assets/wallpaper.jpg",
  "logo": "https://example.com/assets/logo.png",
  "sites": [
    {
      "key": "example_cms_json",
      "name": "示例站-标准JSON采集",
      "type": 1,
      "api": "https://example.com/api.php/provide/vod",
      "searchable": 1,
      "changeable": 1,
      "categories": ["电影", "电视剧", "动漫", "综艺"]
    },
    {
      "key": "example_cms_xml",
      "name": "示例站-XML采集",
      "type": 0,
      "api": "https://cms.example.org/api.php/provide/vod/at/xml",
      "searchable": 1,
      "changeable": 1
    },
    {
      "key": "example_spider_node",
      "name": "示例站-独立爬虫源",
      "type": 3,
      "api": "https://rules.example.net/spider/site_adapter.js",
      "searchable": 1,
      "changeable": 0,
      "ext": "https://rules.example.net/spider/config.json"
    }
  ],
  "parses": [
    {
      "name": "聚合直链解析",
      "type": 0,
      "url": "https://parse.example.com/jx/?url="
    }
  ],
  "rules": [
    {
      "name": "通用广告分片过滤规则",
      "hosts": ["cdn.example.com", "ad-stream.example.org"],
      "regex": ["#EXT-X-DISCONTINUITY\\r?\\n#EXTINF:[0-9.]+,\\r?\\nhttps?://[^\\r\\n]+ad[^\\r\\n]+"]
    }
  ]
}
```

### 2. 配置字段与参数详细说明

#### 根字段（Root Level）

| 参数名称 | 类型 | 说明 |
| :--- | :---: | :--- |
| `spider` | `String` | 可选。自定义 Android/Java 爬虫包（jar）地址。在 Windows 端会自动标记为加固虫包防护项。 |
| `wallpaper` | `String` | 可选。背景壁纸图片地址。 |
| `logo` | `String` | 可选。配置源标识图标。 |
| `sites` | `Array` | **必需**。站点列表，每个对象定义一个采集站点或爬虫数据源。 |
| `parses` | `Array` | 可选。第三方嗅探/解析接口列表。 |
| `rules` | `Array` | 可选。广告切片或域名的正则拦截规则。 |

#### 站点对象字段（`sites[]`）

| 参数名称 | 类型 | 默认值 | 详细功能与作用 |
| :--- | :---: | :---: | :--- |
| **`key`** | `String` | *自动生成* | **站点唯一标识符**。用于在数据库中绑定收藏记录、观看历史和默认站点。 |
| **`name`** | `String` | *自动填充* | **显示名称**。在主界面站点切换下拉框、跨站聚合标签上呈现的文字。 |
| **`type`** | `Integer` | `0` | **数据源协议类型**：<br>• `0`：传统 XML/JSON 通用 CMS 采集接口；<br>• `1`：标准苹果 CMS / 现代 JSON 采集接口（支持完整分页、参数过滤与搜索）；<br>• `3`：Spider / 爬虫脚本类数据源。 |
| **`api`** | `String` | `""` | **数据源接口 URL**：<br>• 对 `type: 0/1` 为 CMS 接口地址（如 `https://example.com/api.php/provide/vod`）；<br>• 对 `type: 3` 为对应的 `.js` 爬虫脚本地址或爬虫名称。 |
| **`searchable`** | `Integer` | `1` | **是否参与全站聚合搜索**：<br>• `1`：允许在「全站搜索」时并发查询本站点；<br>• `0`：仅在手动进入该站点时可检索，全站聚合时不检索该站。 |
| **`changeable`** | `Integer` | `1` | **是否参与同片源自动换源**：<br>• `1`：在影片详情页作为同片源备用线路展示；<br>• `0`：不参与跨站同片源换源匹配。 |
| **`categories`** | `Array` | `[]` | **分类白名单与展示顺序**：<br>字符串数组（例如 `["电影", "国产剧", "美剧"]`）。设置后仅展示数组中指定的分类，并严格按此顺序排序；留空则展示采集站提供的所有原始分类。 |
| **`ext`** | `String` | `""` | 可选。爬虫脚本拓展参数，通常用于传递 Token、JSON 扩展配置链接或鉴权 Cookie。 |

## 四、常用操作与核心功能指南

### 1. 配置源管理与一键同步
- **添加新配置**：点击顶栏 **「＋ 添加」**，粘贴配置源 URL，可在第二行自定义名字；
- **切换配置源**：顶栏左侧下拉框选中即可瞬间生效；
- **手动强制同步（🔄 同步）**：顶栏 **「管理」** ➔ 任意源后的 **`🔄 同步`**：强制绕过本地快照拉取远程定义，有更新即时热生效并提示「✨ 已更新至最新（新增 N 站，共 XX 站）」。

### 2. 广告处理：剪辑 / 跳过

顶栏「广告拦截」右侧的下拉框：

| 方式 | 行为 | 适用 |
| :--- | :--- | :--- |
| **广告：剪辑（默认）** | 开播前把广告块从播放列表整块删除，播放器拿到的是干净流，片长会少掉广告那几十秒 | 日常首选，无跳转卡顿 |
| **广告：跳过** | 保留原始列表，播到广告区间自动跳走 | 源结构异常、剪辑后画面异常时的备选 |

- 切换后**重新打开该集**生效；状态会记住。
- 调试面板：播放中按 **`D`**（或顶栏 **🐞 调试**）查看判定依据——`方式`、每段广告的起止与跳转目标、全部分块的 `时长/分片数`（★ = 判定为广告），面板右下角「复制」可直接贴出来反馈问题。
- 片头/片尾标记与广告处理互不干扰：片尾按「距结尾秒数」记录，剪辑变短也会自动跟着走。

### 3. 播放内核切换（双核 + 外部）
- **内核切换**：默认 **`mpv`**，可在 **`网页 (MSE)`** / **`ffmpeg (兼容)`** 之间切换，自动保留精确进度并记住选择；兼容模式只在检测到时间戳重置时才会被自动启用，起播比 mpv 慢（要等转封装），属备用方案。
- **缓冲**：面板「缓冲」下拉对三个内核都生效（默认 120 秒）；网络不稳调大、想省内存调小，改完重开该集生效。
- **调用 PC 本地播放器**：点右上角 **「用 PC 播放器播放」**，自动检测本机已装的 PotPlayer / VLC / mpv / MPC-HC / ffplay，并把起始秒数一并传过去。

### 4. 虫包站源（JVM）

- 站点下拉里带 **🧩 JVM 虫包** 标记的就是 dex 虫包站点，可直接选中、搜索、播放。
- **首次**加载某个虫包站点需要 10~20 秒（下载 jar → 解壳 → 转为 JVM 类）；同一个站点第二次起是毫秒级。
- 设置面板里能看到 **站源服务（JVM 虫包）** 状态，卡住时可点「重启服务」；日志在 `data\jvm\service.log`。
- 虫包给的地址常要求 Referer/Origin：程序会自动带上，并把分片改写成同源代理，MSE 内核也能播。
- 虫包站点进入分类后，分类标签下方会出现站源自带的**筛选项**（类型/地区/年份/语言/字母/排序），选中后按 `extend` 重新查询；切站点会自动清空。
- 运行时缺失（例如自己 clone 的源码包）时虫包站点会自动禁用，普通站点不受影响；补齐方法：`tools\fetch-jvm.ps1`。

### 5. 全局摸鱼老板键（Boss Key）
- 默认 **`Alt+Q`**：瞬间隐藏窗口与任务栏图标，同时静音暂停；
- 再按一次唤醒并置顶，**保持暂停**，不会突然出声；
- 顶栏 **「🐟 摸鱼键」** 可自定义快捷键或停用。

### 6. 端口更换
默认 `3980` 被占用时，改根目录 `port.txt`（如 `3988`）后重启。

## 五、数据存储与备份还原

KimBoxPC 使用 **SQLite** 存储本地数据，统一放在 `data/` 目录：

```
data/
 ├── tvbox.db          # 主数据库（配置源、收藏、播放历史、片头片尾标记）
 ├── tvbox.db-wal      # SQLite 预写日志
 ├── boss-key.json     # 摸鱼键个性化配置
 ├── window-state.json # 窗口尺寸/位置
 ├── app.log           # 运行日志（超过 512KB 自动轮转）
 ├── cache/            # 配置源本地快照（0ms 秒开）
 └── backups/          # 数据库备份（自动 5 份滚动 + 手动永久）
```

### 备份机制
- **自动备份**：启动、清理数据或还原前自动备份（最多保留最新 5 份，自动滚动）；
- **手动备份**：顶栏 **「备份」** ➔ **「＋ 新建备份」**，永久保留、绝不覆盖；
- **一键还原**：备份面板选中任一条 ➔ **「还原」**，会先自动再备份一次当前数据。

### 缓存清理
顶栏 **「清理缓存」** 仅清理 `%APPDATA%\KimBoxPC` 下的 Chromium 渲染缓存与海报缩略图，**不会删除**配置源、收藏与播放历史。

## 六、常见问题与排错指引 (FAQ)

### Q1：启动时弹出「Windows 已保护你的电脑」提示？
> Windows Defender SmartScreen 对未签名的独立程序默认拦截。点 **「更多信息」➔「仍要运行」** 即可；安装版与便携版都一样。

### Q2：启动提示「libmpv-2.dll 加载失败」或程序闪退？
> 1. 便携版解压前是否解除了文件锁定？右键压缩包 ➔ 属性 ➔ 解除锁定后重新解压；
> 2. 运行根目录 **`修复运行环境.bat`** 补齐 VC++ 运行库；
> 3. 检查杀软是否隔离了 `native\lib\libmpv-2.dll` 或 `native\lib\vulkan-1.dll`；
> 4. 详细原因看 `data\app.log`。

### Q3：播放某些剧集音频变调、发闷、破音或没声音？
> 多为采集站转码导致的时间戳重置（HLS DISCONTINUITY）：
> - 优先用默认 **`mpv 内核`**，libmpv 直连声卡会自动矫正；
> - 兼容模式内置转封装重平衡，把时间戳理顺后再播。

### Q4：用了「剪辑」后，片长比源站短了半分钟？
> 正常：剪辑把广告块整段删掉了，所以片长 = 正片时长。截图里 46:45 变 45:53，少掉的正是两段 25 秒广告。

### Q5：剪辑模式和跳过模式来回切，续播位置差了几十秒？
> 两种方式的时间轴不同（剪辑后不含广告），历史与片头片尾按**当时使用的方式**记录，切换后会有几十秒偏差，不会跳错集。固定用一种方式即可避免。

### Q6：某集广告没被删/没被跳过？
> 播放中按 **`D`** 打开调试面板：
> - `方式` 看当前是剪辑还是跳过；
> - `分块` 里 ★ 标记的就是判定为广告的块，能看出是「没识别出来」还是「识别了没生效」；
> - 点「复制」把内容贴出来即可定位。多数情况是广告与正片没有 discontinuity 分隔（结构上无法定位）。

### Q7：换了电脑或移动了文件夹，快捷方式打不开？
> 便携版移动目录后，重新双击一次 **`创建快捷方式.bat`** 即可重建；安装版请重新运行安装包选择新目录。

## 七、开发者：打包与验收

| 目的 | 操作 |
| :--- | :--- |
| 生成便携版 zip | 双击 **`打包发布.bat`** → 上级目录得到 `KimBoxPC_v<版本>.zip` |
| 生成安装版 exe | 双击 **`制作安装包.bat`** → 上级目录得到 `KimBoxPC_v<版本>_Setup.exe`（需 Inno Setup 6：`winget install --id JRSoftware.InnoSetup -e`） |
| 重新编译原生模块 | 双击 **`tools\编译原生模块.bat`**（必须用 Electron 自带 node，勿直接 `npm run build:native`） |
| 广告验收（跳过模式） | `node tools\accept-ads.js 尚公主` |
| 广告验收（剪辑模式） | `node tools\accept-ads-cut.js 尚公主` |
| 兼容模式验收 | `node tools\accept-compat.js 尚公主 "" cut`（或 `skip` / `both`） |
| 只跑后端调试 | `npm start` → http://127.0.0.1:3980/ |

> 验收脚本会逐个站点真实起播并校验「广告是否被处理、片长是否正确、跳转后是否继续播」，需要 App 或 `node server.js` 在跑。
