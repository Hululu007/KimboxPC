# KimBoxPC 桌面版

基于 **FongMi / TVBox** 核心协议理念打造的 Windows PC 桌面影音播放客户端。

已全面剔除在 PC 端冗余的特性（如投屏、复杂弹幕、手机端手势），专注于极致纯粹的大屏观影体验：**多配置源秒级热切换 ➔ 毫秒级极速检索 ➔ 智能线路聚合 ➔ libmpv 原生渲染无缝播放 ➔ 智能跳过广告与片头片尾 ➔ 摸鱼老板键一键隐藏**。

> **当前版本**：`v3.14.17`（版本由 `package.json` 驱动，完整更新履历详见 [更新.md](更新.md)）。

## 一、核心特性

- ⚡ **0ms 本地快照秒开与热同步（Hot-Reload）**：
  冷启动时优先从本地持久化快照（`data/cache/config_<id>.json`）瞬间恢复，杜绝启动白屏与竞态超时；同时后台静默拉取远程更新，检测到新增站点或域名修复时自动热替换，无需重启程序。
- 🎬 **原生双核播放引擎**：
  - **mpv 原生内核（默认推荐）**：集成 `libmpv` 原生渲染模块与 Vulkan/Direct3D 加速，内存帧直通 `<canvas>`，音频直连声卡绕开浏览器 MSE 解码瓶颈，拖拽秒响应、音画不发闷变调。
  - **ffmpeg (兼容内核)**：内置服务端流式轻量转封装引擎，专门修复时间戳异常（DISCONTINUITY）的老旧片源。
  - **一键外调 PC 本地播放器**：支持检测并拉起系统已安装的 **PotPlayer / VLC / mpv / MPC-HC / ffplay**，并无缝同步起播进度。
- 🔍 **跨站多源并发聚合搜索**：
  一键切换「本站搜索 / 全站搜索」，全站模式下并发向当前配置源的所有可用站点发起探测（20~30 个站点平均 3~6 秒内聚合成片），智能清洗片名不可见零宽字符，同名影视精准去重合并，并实时展示响应延迟与可用线路数。
- ⏭️ **播放断点进度无缝继承**：
  换源、切线路、切集数或切换播放引擎时，统一提取并保留精确到毫秒的绝对播放秒数，新流就绪后自动平滑续播，不再重播开头。
- 🚫 **智能广告拦截与片头片尾标记**：
  内置 m3u8 广告切片识别过滤，播放时自动跳过插播广告；支持按片名一键标记片头片尾，整部剧集自动跳过，无需手动快进。
- 🐟 **全局摸鱼老板键（Boss Key）**：
  默认全局快捷键 `Alt+Q`，按下瞬间隐藏软件窗口与任务栏图标，同时彻底静音暂停音视频；再次按下即刻唤醒窗口，保持暂停状态等待手动恢复，安心无痕。

## 二、运行环境与安装指南

### 1. 运行要求

KimBoxPC 采用完全**绿色便携式**架构打包，**目标电脑不需要单独安装 Node.js**（Electron 已内置 Node.js 运行时环境）。

| 组件 | 是否必需 | 说明 |
| :--- | :---: | :--- |
| **Windows 操作系统** | ✅ 必需 | Windows 10 / Windows 11 (64 位) |
| **Electron 运行时** | ✅ 必需 | 位于项目 `node_modules\electron\` 目录 |
| **libmpv 原生动态库** | ✅ 必需 | 位于 `native\lib\` 及 `native\build\Release\mpv_native.node` |
| **VC++ 2015-2022 运行库** | ✅ 必需 | 若电脑缺失，可直接运行随包提供的 `tools\VC_redist.x64.exe` |
| **随附 ffmpeg 组件** | ⚪ 备用 | 位于 `ffmpeg\ffmpeg.exe`，供「ffmpeg (兼容)」内核转封装使用 |
| **Node.js (系统环境)** | ❌ 不需要 | 桌面版开箱即用，无需配置系统环境变量 |

### 2. 首次安装与使用步骤

1. **解压前解除文件锁定（重要）**：
   下载压缩包后，**右键点击 `.zip` 压缩包 ➔「属性」➔ 勾选底部的「解除锁定」➔ 点击「确定」**，然后再进行解压。
   > *说明：Windows 对网络下载的文件会默认添加安全标记，不解除锁定可能导致动态链接库（`libmpv-2.dll`）被系统拦截阻止加载。*

2. **完整解压整个项目目录**：
   解压到任意英文或中文路径均可（例如 `D:\Software\KimBoxPC`），请保持所有子文件夹结构完整。

3. **创建桌面快捷方式**：
   进入解压后的文件夹，双击运行 **`创建快捷方式.bat`**，程序会自动在桌面生成带有官方图标的 `KimBoxPC 桌面版` 快捷方式。

4. **环境体检与一键修复（备用）**：
   如果首次双击启动出现报错或提示缺少运行库，直接双击运行根目录下的 **`修复运行环境.bat`**。该脚本会自动：
   - 检测 VC++ 运行库完整性，若缺失将直接静默调用随包离线安装包 `tools\VC_redist.x64.exe` 进行补全；
   - 自动批量解除目录下全部文件的系统安全锁定；
   - 检验 Vulkan / libmpv 核心文件完好性。

5. **启动程序**：
   双击桌面的 **`KimBoxPC 桌面版`** 快捷方式（或文件夹中的 `KimBoxPC-桌面版.bat`）即可进入主界面。

## 三、配置文件范例与参数详解

KimBoxPC 完整兼容标准的 **TVBox / FongMi (蜂蜜)** 订阅配置协议，支持传入标准的远程 `http(s)://` JSON 订阅链接，或本地 JSON 文件路径。

> ⚠️ **规范声明**：下文所有配置均为语法结构教学范例，包含的域名均为纯示例假地址（如 `example.com`），**不指向任何真实服务器**。在实际使用中，请换入合法有效的配置内容。

### 1. 标准 JSON 配置文件范例

```json
{
  "spider": "https://example.com/spiders/custom_spider.jar",
  "wallpaper": "https://example.com/assets/wallpaper.jpg",
  "logo": "https://example.com/assets/logo.png",
  "sites": [
    {
      "key": "example_cms_json",
      "name": "示例站-标准JSON采集",
      "type": 1,
      "api": "https://example.com/api.php/provide/vod",
      "searchable": 1,
      "changeable": 1,
      "categories": ["电影", "电视剧", "动漫", "综艺"]
    },
    {
      "key": "example_cms_xml",
      "name": "示例站-XML采集",
      "type": 0,
      "api": "https://cms.example.org/api.php/provide/vod/at/xml",
      "searchable": 1,
      "changeable": 1
    },
    {
      "key": "example_spider_node",
      "name": "示例站-独立爬虫源",
      "type": 3,
      "api": "https://rules.example.net/spider/site_adapter.js",
      "searchable": 1,
      "changeable": 0,
      "ext": "https://rules.example.net/spider/config.json"
    }
  ],
  "parses": [
    {
      "name": "聚合直链解析",
      "type": 0,
      "url": "https://parse.example.com/jx/?url="
    }
  ],
  "rules": [
    {
      "name": "通用广告分片过滤规则",
      "hosts": ["cdn.example.com", "ad-stream.example.org"],
      "regex": ["#EXT-X-DISCONTINUITY\\r?\\n#EXTINF:[0-9.]+,\\r?\\nhttps?://[^\\r\\n]+ad[^\\r\\n]+"]
    }
  ]
}
```

### 2. 配置字段与参数详细说明

#### 根字段（Root Level）

| 参数名称 | 类型 | 说明 |
| :--- | :---: | :--- |
| `spider` | `String` | 可选。自定义 Android/Java 爬虫包（jar）地址。在 Windows 端会自动标记为加固虫包防护项。 |
| `wallpaper` | `String` | 可选。背景壁纸图片地址。 |
| `logo` | `String` | 可选。配置源标识图标。 |
| `sites` | `Array` | **必需**。站点列表，每个对象定义一个采集站点或爬虫数据源。 |
| `parses` | `Array` | 可选。第三方嗅探/解析接口列表。 |
| `rules` | `Array` | 可选。广告切片或域名的正则拦截规则。 |

#### 站点对象字段（`sites[]`）

| 参数名称 | 类型 | 默认值 | 详细功能与作用 |
| :--- | :---: | :---: | :--- |
| **`key`** | `String` | *自动生成* | **站点唯一标识符**。用于在数据库中绑定收藏记录、观看历史和默认站点。 |
| **`name`** | `String` | *自动填充* | **显示名称**。在主界面站点切换下拉框、跨站聚合标签上呈现的文字。 |
| **`type`** | `Integer` | `0` | **数据源协议类型**：<br>• `0`：传统 XML/JSON 通用 CMS 采集接口；<br>• `1`：标准苹果 CMS / 现代 JSON 采集接口（支持完整分页、参数过滤与搜索）；<br>• `3`：Spider / 爬虫脚本类数据源。 |
| **`api`** | `String` | `""` | **数据源接口 URL**：<br>• 对 `type: 0/1` 为 CMS 接口地址（如 `https://example.com/api.php/provide/vod`）；<br>• 对 `type: 3` 为对应的 `.js` 爬虫脚本地址或爬虫名称。 |
| **`searchable`** | `Integer` | `1` | **是否参与全站聚合搜索**：<br>• `1`：允许在「全站搜索」时并发查询本站点；<br>• `0`：仅在手动进入该站点时可检索，全站聚合时不检索该站。 |
| **`changeable`** | `Integer` | `1` | **是否参与同片源自动换源**：<br>• `1`：在影片详情页作为同片源备用线路展示；<br>• `0`：不参与跨站同片源换源匹配。 |
| **`categories`** | `Array` | `[]` | **分类白名单与展示顺序**：<br>字符串数组（例如 `["电影", "国产剧", "美剧"]`）。设置后仅展示数组中指定的分类，并严格按此顺序排序；留空则展示采集站提供的所有原始分类。 |
| **`ext`** | `String` | `""` | 可选。爬虫脚本拓展参数，通常用于传递 Token、JSON 扩展配置链接或鉴权 Cookie。 |

## 四、常用操作与核心功能指南

### 1. 配置源管理与一键同步
- **添加新配置**：点击顶栏右侧 **「＋ 添加」** 按钮，粘贴配置源 URL，可在第二行自定义方便记忆的名字；
- **切换配置源**：直接在顶栏左侧下拉框中选中即可瞬间生效；
- **手动强制同步（🔄 同步）**：点击顶栏 **「管理」** 按钮，在弹出的配置源列表中点击任意源后的 **`🔄 同步`** 按钮：
  - 强制绕过本地快照向远程服务器获取最新定义；
  - 若有更新：即时热生效，界面展示 `✨ 已更新至最新（新增 N 站，共 XX 站）`；
  - 若无变动：给出明确正反馈 `✅ 已是最新版本（共 XX 站，暂无更新）`；
  - 条目下方及屏幕顶部均会滑出提示，所见即所得。

### 2. 播放内核切换（双核 + 外部）
- **内核切换**：在播放控制区或详情页选集面板中，可随时在 **`mpv 内核`** 与 **`ffmpeg (兼容)`** 之间切换。系统会自动记录精确进度，无缝平移至新内核重载播放；
- **调用 PC 本地播放器**：点击右上角红色 **「用 PC 播放器播放」** 按钮，系统自动检测本机安装的外部播放器并在下拉列表中记忆，点击即可将流地址与起始播放秒数精准传给外部播放器继续欣赏。

### 3. 全局摸鱼老板键（Boss Key）
- **默认快捷键**：全局按下 **`Alt+Q`**；
- **行为模式**：瞬间隐藏软件主窗口并将其从任务栏撤下，同时彻底静音并暂停音视频；
- **唤醒保护**：再次按下 `Alt+Q` 唤醒窗口并置顶，**唤醒后保持暂停状态**，绝不突发声音外放，需用户手动确认点击播放；
- **自定义快捷键**：点击顶部 **「🐟 摸鱼键」** 按钮可自定义热键（如 `Ctrl+Shift+H`）或停用老板键。

### 4. 端口更换（解决端口被占用）
若默认端口 `3980` 被本地其他服务占用，可使用文本编辑器打开根目录下的 **`port.txt`**，填入未被占用的端口号（例如 `3988`），重新启动软件即可。

## 五、数据存储与备份还原

KimBoxPC 采用高性能轻量数据库 **SQLite** 存储本地数据，文件统一存放在 `data/` 目录：

```
data/
 ├── tvbox.db          # 主数据库（配置源列表、收藏记录、播放历史、跳过标记）
 ├── tvbox.db-wal      # SQLite 预写日志
 ├── boss-key.json     # 摸鱼键个性化配置
 ├── cache/            # 配置源本地快照（支持离线 0ms 秒开）
 └── backups/          # 数据库快照备份存档
```

### 备份机制
- **自动备份**：在软件启动、清理数据或恢复配置前，系统自动在 `data/backups/` 备份一份副本（最多保留最新的 5 份，多余的自动滚动清理）；
- **手动备份**：点击顶栏 **「备份」** 按钮 ➔ **「＋ 新建备份」**，手动备份永久保留，绝不自动覆盖；
- **一键还原**：在备份面板中选择任一备份条目，点击 **「还原」** 即可瞬间回退至对应时空节点。

### 缓存清理
- 点击顶栏 **「清理缓存」** 按钮，系统会**仅清理** `%APPDATA%\KimBoxPC` 目录下的 Chromium 临时渲染和海报缩略图文件，**绝不会删除**你的配置源、收藏夹和播放历史。

## 六、常见问题与排错指引 (FAQ)

### Q1：启动时弹出「Windows 已保护你的电脑」提示？
> 这是 Windows Defender SmartScreen 对未购买商业数字签名的独立开发程序的默认保护机制。点击窗口中的 **「更多信息」➔「仍要运行」** 即可。

### Q2：启动提示「libmpv-2.dll 加载失败」或程序闪退？
> 请按以下顺序排查解决：
> 1. 解压前是否未勾选解除锁定？请右键压缩包解除锁定后再解压覆盖；
> 2. 双击运行根目录下的 **`修复运行环境.bat`**，根据提示自动补齐 VC++ 运行库；
> 3. 检查安全防护软件是否误隔离了 `native\lib\libmpv-2.dll` 或 `native\lib\vulkan-1.dll`。

### Q3：播放部分剧集时音频变调、发闷、破音或没有声音？
> 这是由于部分盗链采集站转码时导致的时间戳重置（HLS DISCONTINUITY）问题：
> - 推荐直接使用默认的 **`mpv 内核`** 播放，底层 libmpv 直连声卡会自动矫正音轨；
> - 若使用兼容模式，系统已内置自适应流式转封装重平衡机制。

### Q4：换了新电脑或移动了文件夹位置后，快捷方式打不开？
> Windows 快捷方式记录了绝对路径。移动目录后，只需双击运行一次根目录下的 **`创建快捷方式.bat`**，即可自动重建正确的桌面快捷方式。
